# 素材目录使用说明

AI 回复可以携带标记，系统自动把标记变成真实的微信发送动作。

## 目录

| 目录 | 用途 | 标记 |
|------|------|------|
| `assets/images/` | 图片（png/jpg/jpeg/gif/bmp/webp） | `[IMAGE:文件名]` |
| `assets/files/` | 任意文件（不限扩展名） | `[FILE:文件名]` |
| `stickers/` | 表情包（gif/png/jpg 等，按图片通道发送） | `[STICKER:文件名]` |

## 名称写法

- 带扩展名：`[IMAGE:商品海报.png]`（精确匹配）
- 不带扩展名：`[IMAGE:商品海报]`（自动匹配常见扩展名）
- 绝对路径也可以，但推荐放目录里用文件名，方便 AI 从清单中选取

## 工作流程

1. 把素材文件放进对应目录
2. AI 生成回复时，系统提示词会自动注入当前素材清单
3. AI 在需要时输出标记，例如：`这款很适合你[呲牙] [IMAGE:商品海报.png]`
4. 系统拆成片段依次发送：文字（逐字输入，可混微信内置表情）→ 随机间隔 1~3 秒 → 图片

## 注意

- 素材缺失时只跳过该片段并记日志，不会中断其他片段
- 文字中的 `[呲牙]` `[微笑]` 等是微信内置表情短代码，原样发送即可，不是媒体标记
- 媒体发送同样受每小时回复配额和连续失败熔断保护
