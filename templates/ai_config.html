通用智能体接入说明
工作原理 - 微信收到消息 → 本程序把消息文字 POST 到你的智能体接口 → 接口返回回复文字 → 本程序在微信中发送。密钥仅用于接口鉴权，智能体本身仍在平台云端运行
OpenAI 兼容协议 - 适合豆包（火山方舟）等标准接口，填 Base URL + API Key + 模型/接入点 ID 即可
通用 Webhook - 适合自己做的智能体：系统会向你的地址 POST JSON {"message": "用户消息", "contact": "联系人", "history": [...]}， 返回 JSON 里包含 reply / text / answer / output / content 任一字段即作为回复（支持嵌套在 data/result 里）
鉴权 - 填了 API Key 会带 Authorization: Bearer <key> 请求头
